# Velocity Whitelist

A whitelist for your velocity proxy

## Config

The plugin stores the whitelisted players inside a database which can be configured in `plugins/velocitywhitelist/config.yml`.

## Usage

```
/vwl enable
/vwl disable
/vwl add <player>
/vwl remove <player>
/vwl list
```

## Permissions

Permissions are `vwl.<command>`. For example: `vwl.list`.
